# 스트릭 / 진행감 스펙 (리텐션)

> 사용자가 **다시 돌아올 이유**를 만드는 가벼운 진행 지표. 서버·계정 없이 기존 기보 데이터에서 파생한다.
> 기보 저장 구조는 [nav.md §5](nav.md), 대국 모드는 [game-modes.md](game-modes.md) 참조.

## 1. 배경 / 목적

기존에도 통계(총 대국·승률·난이도별)는 있었으나 **프로필 탭 안에 묻혀 있어** 사용자가 일부러 찾아가야 보였다. 리텐션은 지표의 존재가 아니라 **눈에 띄는 시점**에서 나온다.

따라서 (1) **스트릭 지표를 추가**하고, (2) 이를 **사용자가 반드시 지나는 지점**에 노출한다.

## 2. 지표 정의

**출석 스트릭이 주인공이다.** 승패와 무관하게 쌓이므로 좌절이 없고, 습관 형성에 직접 기여한다. 연승은 보조 지표로 성취감을 담당한다.

### 2-1. 출석 스트릭 (연속 플레이 일수) — 주 지표

- **정의**: 하루에 1판 이상 둔 날이 연속으로 이어진 일수.
- 판정 기준은 **로컬 시간대의 날짜**(`YYYY-MM-DD`)다.
- **현재 스트릭**: 오늘 또는 어제 플레이한 기록이 있으면 이어지는 것으로 본다.
  - 마지막 플레이가 **오늘**이면 오늘까지 포함해 연속 일수를 센다.
  - 마지막 플레이가 **어제**면 어제까지의 연속 일수를 유지한다(오늘 두면 +1).
  - 마지막 플레이가 **그 이전**이면 현재 스트릭은 `0`이다.
- **최고 기록**: 전체 기간 중 가장 길었던 연속 일수.

### 2-2. 연승 스트릭 — 보조 지표

- **정의**: 가장 최근 대국부터 거슬러 올라가며 이어지는 연속 승리 수.
- 판정: **승은 +1, 패는 초기화(0), 무승부는 유지(증가 없음)**.
- **최고 기록**: 전체 기간 중 가장 길었던 연승.

### 2-3. 데이터 소스

- `records.js`의 `loadRecords()` 결과에서 **런타임에 파생**한다. 별도 저장소를 만들지 않는다.
- 기록은 최신순(`unshift`)으로 저장되어 있다.
- 기록이 없으면 모든 값은 `0`이다.

## 3. 기보 레코드 확장

대국 모드([game-modes.md](game-modes.md)) 도입에 따라 저장 레코드에 모드를 추가한다.

| 필드 | 값 | 비고 |
|------|-----|------|
| `mode` | `'quick' \| 'renju'` | 신규. 기존 레코드에 없으면 `'renju'`로 간주(하위 호환) |

## 4. 노출 위치

지표는 다음 **세 지점**에 노출한다. 사용자가 반드시 지나는 경로다.

### 4-1. 시작 화면 상단 — 진입 시

- 로고 아래, 모드 선택 위에 **스트릭 배너**를 표시한다.
- 출석 스트릭을 크게, 연승을 보조로 배치한다.
- 기록이 없으면(첫 사용자) 배너를 **표시하지 않는다** — 빈 지표는 동기를 주지 않는다.
- 오늘 아직 두지 않았고 스트릭이 살아있으면 **이어가기를 유도하는 문구**를 함께 보여준다.

### 4-2. 결과 화면 — 승/패 직후

- `ResultOverlay`에 스트릭 변화를 표시한다. 감정이 가장 높은 시점이다.
- **승리 시 연승이 2 이상이면** 연승을 강조한다(예: `3연승`).
- **출석 스트릭이 갱신된 첫 판**이면 출석 일수를 표시한다.
- 패배 시에는 연승을 강조하지 않는다. 출석 스트릭은 승패 무관하게 표시할 수 있다.

### 4-3. 기보 탭 상단

- 기록 목록 위에 **스트릭 요약 바**를 표시한다(출석·연승 각각 현재/최고).
- 기록이 없으면 기존 빈 상태 화면을 유지한다.

> 프로필 탭의 기존 통계는 변경하지 않는다.

## 5. 구현

| 파일 | 역할 |
|------|------|
| `src/engine/streak.js` | **신규** — 기록 배열 → 스트릭 파생 (순수 함수, UI 비의존) |
| `src/engine/records.js` | 레코드에 `mode` 포함 (저장 시점은 `Game.jsx`) |
| `src/ui/StreakBanner.jsx` | **신규** — 공용 표시 컴포넌트 |
| `src/ui/StartScreen.jsx` | 상단 배너 |
| `src/ui/ResultOverlay.jsx` | 결과 화면 스트릭 표시 |
| `src/ui/RecordsScreen.jsx` | 상단 요약 바 |

`streak.js`는 `engine/` 규칙에 따라 **React/DOM 비의존 순수 JS**로 작성한다.

## 6. 완료 기준 (Acceptance)

- 기록이 없으면 모든 스트릭 값이 `0`이고, 시작 화면에 배너가 나타나지 않는다.
- 같은 날 여러 판을 둬도 출석 스트릭은 **1일로 계산**된다.
- 어제까지 3일 연속 → 오늘 한 판 두면 출석 스트릭이 **4**가 된다.
- 이틀 이상 쉬면 현재 출석 스트릭은 `0`, 최고 기록은 보존된다.
- 연승은 승 +1 / 패 0 / 무 유지로 계산되고, 최고 연승이 보존된다.
- 기존 레코드(`mode` 없음)도 오류 없이 집계된다.
