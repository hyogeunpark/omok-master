# 게임 사이드 패널 (대국 HUD) 스펙

> 대국 화면 오른쪽/아래의 정보·컨트롤 패널(`.game-side`) 구조와 시각 규칙.
> AI 두뇌 표시 문구 자체는 [ai.md §2-2](ai.md), 오프닝 UI는 [opening.md](opening.md)·[swap.md](swap.md), 바텀 네비는 [nav.md](nav.md) 참조.

## 1. 목적

대국 중 사용자가 **누구 차례인지 · CPU가 어떤 두뇌로 얼마나 깊이 읽는지 · 무엇을 조작할 수 있는지**를 한눈에 파악하게 한다. 읽는 화면이 아니라 **훑고 조작하는 HUD**로 취급한다.

## 2. 존(zone) 구조

패널은 **세로 존 스택**으로 구성한다. 이 구조가 반응형의 핵심이다(§5).

| 순서 | 존 | 내용 |
|------|-----|------|
| 1 | 헤더 | 나가기 버튼 |
| 2 | **대국** | 매치업(나 vs CPU) + CPU 두뇌 readout |
| 3 | 오프닝 | 오프닝 진행 UI (오프닝 국면에서만, [opening.md](opening.md)) |
| 4 | **상태** | 사고중 인디케이터 / 차례 표시 |
| 5 | 컨트롤 | 되돌리기 · 새 게임 |

각 정보 존(대국·상태)은 얇은 대문자 라벨(`대국`, `상태`)과 구분선을 가진다.

## 3. 색 규칙 — 나 vs CPU 구분

기존에는 나·CPU가 모두 골드라 시각적 구분이 없었다. 다음과 같이 **역할별 액센트**를 분리한다.

| 역할 | 액센트 | 토큰 |
|------|--------|------|
| 나(사용자) | 골드 | `--accent` (#d4af37) |
| CPU · CPU 사고 상태 | night indigo | `--cpu` (#8b93ff) |

- 매치업에서 내 이름/돌은 골드 계열, CPU 이름/돌은 인디고 계열로 표시한다.
- CPU 두뇌 readout, 사고중 인디케이터(미니보드 스캔선·착수점·텍스트)는 **인디고**를 쓴다.
- 승리/패배 결과 오버레이의 골드는 유지한다(대국 결과는 사용자 관점).

## 4. 타이포 — HUD 데이터는 모노스페이스

숫자·코드성 데이터는 계기판처럼 **모노스페이스 + `tabular-nums`**로 표시해 좁은 폭에서도 정렬이 흔들리지 않게 한다. 본문·한글 설명은 기존 산세리프(Inter)를 유지한다.

| 모노 적용 | 산세리프 유지 |
|-----------|---------------|
| 탐색 깊이 숫자, `VCF` 태그, 존 라벨, 사고 깊이 카운터 | 이름, 안내 문구, 버튼, 한글 설명 |

- 모노 폰트 스택: `ui-monospace, 'SF Mono', 'JetBrains Mono', Menlo, Consolas, monospace` (외부 폰트 로드 없음).
- Orbitron 등 장식적 디스플레이 폰트는 zen 톤과 충돌하므로 쓰지 않는다.

## 5. 반응형

기존 브레이크포인트([index.css])를 그대로 따른다. 존 스택 구조라 두 레이아웃 모두 재작성 없이 동작한다.

| 화면 | 조건 | 레이아웃 |
|------|------|----------|
| 모바일/태블릿 | `< 860px` | 보드 위 · 패널 아래 **전체폭**(~430–560px). 헤더는 가로. |
| 데스크톱 | `≥ 860px` | 보드 왼쪽 고정 · 패널 오른쪽 **사이드바 max 300px**. 헤더는 세로. |

- 매치업(`나 vs CPU`)은 `grid-template-columns: 1fr auto 1fr`로 폭에 무관하게 정렬.
- CPU 두뇌 readout는 `flex-wrap`으로 300px에서도 넘치지 않는다.
- 검증 폭: **375 · 430 · 300px**(사이드바)에서 깨짐 없어야 한다.

## 6. 접근성/모션

- 클릭 가능한 요소는 `cursor: pointer` + `:focus-visible` 아웃라인(역할 색) 제공.
- 사고중 스캔 애니메이션은 `@media (prefers-reduced-motion: reduce)`에서 정지한다.
- 아이콘은 이모지가 아니라 도형/SVG로 표현한다(현행 미니보드·돌 도형 유지).

## 7. 구현 파일

- `src/ui/Game.jsx` — 패널 마크업(존 구조).
- `src/ui/brainLabel.js` — 두뇌 문구(`BRAIN_LABEL`, 카드용) + 구조화 메타(`BRAIN_META`, readout용).
- `src/index.css` — `--cpu` 토큰, 존/매치업/readout/상태 스타일, 반응형 규칙.
