# 게임 모드 스펙 (빠른 대국 / 정석 렌주)

> 앱 진입 시 사용자가 고르는 **대국 모드** 정의. 규칙 차이와 진입 흐름을 규정한다.
> 금수 규칙 자체는 [forbidden.md](forbidden.md), 오프닝 절차는 [opening.md](opening.md), 난이도는 [ai.md](ai.md) 참조.

## 1. 배경 / 목적

기존 앱은 **타라구치-10 오프닝 절차**를 반드시 거쳐야 착수가 시작됐다. 이는 정석 렌주 경험으로는 정확하지만, "짬날 때 잠깐 두는" 캐주얼 사용자에게는 **첫 착수까지의 마찰**이 크다.

따라서 **오프닝 절차를 생략한 빠른 대국 모드**를 기본으로 제공하고, 기존 절차는 정석 모드로 유지한다.

## 2. 모드 정의

| 모드 | 키 | 오프닝(타라구치-10) | 렌주 금수 | 대상 |
|------|-----|------|------|------|
| **빠른 대국** | `quick` | ❌ 생략 — 바로 착수 | ✅ 적용 | 캐주얼 (기본값) |
| **정석 렌주** | `renju` | ✅ 적용 | ✅ 적용 | 기존/숙련 사용자 |

- **금수는 두 모드 모두 유지한다.** 흑 3-3·4-4·장목 금지는 오목의 공정성 핵심이므로 캐주얼에서도 끄지 않는다.
- 두 모드의 차이는 **오프닝 절차 유무 뿐**이다. 승패 판정·AI·보드 규칙은 동일하다.

### 2-1. 빠른 대국의 색 배정

오프닝의 스왑 절차가 없으므로 **게임 시작 시 흑/백을 무작위 배정**한다(`createGame`의 기존 기본 동작). 흑이 선공이며, 흑에게만 금수가 적용되어 균형을 맞춘다.

## 3. 진입 흐름

**모드 선택 → 난이도 선택 → 대국** 순서로 진행한다.

```
[시작 화면]
   ├─ 빠른 대국 (기본/권장)  ──┐
   └─ 정석 렌주               ──┴─→ [난이도 선택] → [대국]
```

- 시작 화면은 **모드 카드 2개**를 먼저 보여준다. 각 카드에는 모드명·한 줄 설명·규칙 요약(오프닝 유무)을 표시한다.
- 모드를 고르면 기존 **난이도 카드 3개**([ai.md §2](ai.md)) 화면으로 전환한다.
- 난이도 화면에서는 **뒤로 가기**로 모드 선택으로 돌아갈 수 있다.
- 빠른 대국을 **기본/권장**으로 시각적 우선순위(상단 배치)를 준다.

## 4. 대국 중 표시

- 게임 HUD([game-hud.md](game-hud.md))의 대국 존에 **현재 모드**를 표시한다.
- 빠른 대국에서는 오프닝 UI(스왑·분기·후보 선택)를 렌더하지 않는다.
- 금수 표시(금수 자리 마커)는 두 모드 모두 동일하게 동작한다.

## 5. 구현

| 파일 | 역할 |
|------|------|
| `src/ui/StartScreen.jsx` | 모드 선택 → 난이도 선택 2단계 화면 |
| `src/App.jsx` | `{ mode, difficulty }` 설정을 `Game`에 주입 |
| `src/ui/Game.jsx` | `createGame({ useOpening: mode === 'renju' })` |
| `src/engine/game.js` | **기존 그대로** — `useOpening` 옵션과 `!game.opening` 금수 적용이 이미 존재 |

> 엔진은 이미 `createGame({ useOpening: false })`를 지원하고, 금수는 오프닝이 끝난 뒤(`!game.opening`)에 적용된다. 따라서 빠른 대국은 **엔진 변경 없이** UI 배선만으로 성립한다.

## 6. 완료 기준 (Acceptance)

- `createGame({ useOpening: false })`로 만든 게임은 `opening === null`이고 첫 수부터 바로 착수된다.
- 빠른 대국에서도 흑의 3-3/4-4/장목은 금수로 거부된다.
- 정석 렌주는 기존 타라구치-10 절차가 그대로 동작한다(회귀 없음).
- 시작 화면에서 모드 → 난이도 순으로 선택 가능하고, 난이도 화면에서 뒤로 갈 수 있다.
